# Put your photos in this folder

Name each file **exactly** as listed and it appears on the site automatically.
No code to write.

## The quickest way to know what's missing

Open the site in a browser. **Every empty photo slot shows a small dark tag in
its corner naming the exact file it wants** — like `add images/hero-1.jpg`. The
tag disappears the moment you add that file. So you never have to guess: just
look at the page and add whatever the tags are asking for.

**Nothing breaks if a photo is missing.** That spot shows a colored placeholder
until the file exists, so you can add them one at a time, in any order.

## Uploading from GitHub (no software needed)

1. Open the `images` folder (or `images/blog`) here on GitHub
2. **Add file → Upload files**
3. Drag your photos in
4. **Commit changes**

Refresh the site and they're live.

## Rules of thumb

- **Names are case-sensitive.** `Hero-1.JPG` will not work — use `hero-1.jpg`.
- **The file type matters.** A photo saved as `hero-1.png` won't be found,
  because the site looks for `hero-1.jpg`. Re-save it as a `.jpg` first. Use
  `.jpg` for photos and `.png` for the logo, so the logo's background stays
  transparent.
- **Landscape beats portrait.** Tall photos get cropped to the middle.
- **Keep each file under about 1 MB** or the page loads slowly. Search
  "compress jpeg" for a free tool — a 5 MB photo usually drops to a few hundred
  KB with no visible difference.

## Changing a filename

All the main filenames live in one block near the bottom of `index.html`,
marked **YOUR PHOTOS** in a box. Blog filenames sit next to each post in the
same file — search for `images/blog/` to find them.
